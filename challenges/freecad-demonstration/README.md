# 02 · FreeCAD 绘图、画框与中文描述

用 FreeCAD 画一个能随桥板高度变化的支撑柱，为已有的五孔圆盘操作画框，再替另一段布尔融合操作补中文说明。三个作业来自不同零件，每项都能单独开考。[完整考生题面](candidate/任务.md)

| 作业 | 考生实际做什么 | 独立考官检查什么 |
| --- | --- | --- |
| A · 画桥架 | 从空白文档用 GUI 搭好底板、端柱和桥板，在底板中心画 Ø12 支撑，用 Up to face 连到桥底。交可编辑 FCStd、逐步截图与实际动作、保存凭据 | 重开重算，测单实体形状与面引用。临时把桥板抬高 5 mm，检查中央柱是否跟随。核对 GUI 记录与模型 |
| B · 给五孔圆盘画框 | 在 63 个既有动作中，为点击及拖动的两个端点标出所指目标，交 boxes.json | 逐一回看 53 张动作前图上的 56 个目标。落点、所指对象、是否混入相邻控件分别核实 |
| C · 补双柱融合的中文描述 | 看 90 个动作前图及末帧，逐步写清前一状态、目的、可见证据与下一动作，交 intents.json | 对照树、视图和动作字段，核对对象、数值、输入方式及错误后的恢复，接受同义表达 |

**设计评级为 L2／D2。** 规格、工位和交卷条件已给定，考生自己选择建模和标注方法。最难的建模环节要求把草图、实体与终止面正确关联。三个作业独立计分。评级尺度见[分级说明](../../RATINGS.md)。

### 开考与判卷

1. 组织者只向考生提供 `candidate/`，做 A 时再提供 FreeCAD 和录制工具。所附 [Windows GUI 工位](station/README.md)支持单机后台操作。考生可以用图像工具放大 B、C 原图。
2. 保存本次交卷，冻结文件，再交给另一个独立上下文的考官。题库公开了参考答案，正式盲测需由组织者限制考生对题库和网络的读取。公开工位负责 GUI 录制，文件访问权限由运行环境控制。
3. 考官用标准 Python 运行 `python -B examiner/review.py --verify-inputs` 校验试卷，然后运行 `python -B examiner/review.py 提交目录 --output measured.json`。PNG 按原始字节核对 SHA-256，JSON 和 Markdown 统一换行后核对。
4. 在能导入 FreeCAD 与 Part 的 Python 中运行 `examiner/inspect_bridge.py 提交目录/bridge.FCStd`。考官配合原图逐项定分并记录理由。[判卷规则](examiner/判卷.md) · [首轮试考记录](首次试考.md)

### 素材出处

原题分别为 CADGUI-GAP-006、010、016。B 取自作者项目的一次 GUI 建模轨迹，C 为作者本人操作记录。作者选取两段录制供本题使用，合计 153 个动作、155 张原图。动作前图与末帧均按次序保留。考生文件去除了参考中文并统一了图像路径，考官参考框可追溯到对应原图。截图中的 FreeCAD 界面与第三方标识保留原有权利。
