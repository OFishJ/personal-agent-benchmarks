# 独立考官说明

用新上下文评阅冻结的交卷副本。先独立看产物，再打开考生自检。B、C 各一个 JSON。A 的真实记录可以是独立目录，通过保存的提交清单定位。保留各项结论、检验覆盖、证据步号和待确认项。试卷分别考察建模、视觉定位和中文语义，分别报告结果。正式通过须满足三个分项的交付要求，有小项失分时保留已完成项及计数。

**A**　在只读副本上重开、重算模型。用带有 FreeCAD 模块的 Python 运行 `inspect_bridge.py bridge.FCStd`。程序对比题面独立构造的几何，读中央 Pad 的圆截面与实际终止面。当识别到可调的立柱特征时，临时抬高 5 mm 检查变更后的实体。容许其他有效的特征顺序、名称和选面编号。程序无法识别的有效建法，另在副本手动调整支柱和桥板并复测。检查额外可见实体、模型保存与记录对应性、N+1、输入和选面图。能证明多少就报告多少，记录有中断或改正需附步号。

**B**　运行 `review.py <提交目录> --output measured.json`。参考框为 1920×1080 图上像素坐标。核对步号、角色、尺寸、实际落点后，回看每个与参考框不同的目标。框边合理伸缩、选中同一操作区域可判正确。包住无关大块区域或把相邻控件一起当作目标应定位说明。普通拖动的两端分别记结果。重叠比是定位争议项的读数，单一阈值不能代替语义判断。报告正确框数、错误框数、缺框及误加框，分母为 56。

所附工位的 A 轨迹可用 `python inspect_trajectory.py 记录目录` 核对步号、前图和末帧文件、PNG 图像头与尺寸。其他录制工具按其格式核对同一要求。识别屏幕所示操作及模型中的面引用仍需考官检查。

**C**　逐步对照原动作、动作前图及参考中文。正确同义句可通过。主要事实包括选中与可见、当前对象、目标值与单位、是否按下回车以及实际失败时的恢复动作。给每步记“可用／明确错误／描述不足／缺失”，同一步有多项问题以最严重者计一次。首步无历史段。逐步列出主要失分依据，总数为 90。参考句与截图冲突时，以图和动作为准并注明。

**首轮校准**　对照同形的两份桥架检查终止类型。一份把支撑柱固定为 30 mm，另一份采用 Up to face，两份初始体积都约 59861.95 mm³。B 和 C 可混入点位偏移、范围过大、合理扩框、同义句、错误前状态及漏回车，预期标签只由宿主持有。发现判卷歧义先区分题面、参考和考生错误。

已附上[固定长度对照件](controls/control_fixed.FCStd)和[随动对照件](controls/control_follow.FCStd)。两件均由组织者生成，用于校准 A 的模型检查。将 Columns 的 Length 从 20 临时调到 25 后，固定长度件在中央柱顶缺少约 565.49 mm³，随动件与变更后的目标几何吻合。对照件的制作方式与考生 GUI 交卷要求分别记录。
