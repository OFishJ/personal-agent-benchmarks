# 02 · FreeCAD 绘图、画框与中文描述

三项分别交卷。所有尺寸单位为 mm。工位提供 FreeCAD、GUI 动作录制与截图能力，B、C 附独立原图和动作。可以用程序查看、裁切放大和整理图像。原图坐标系的原点在左上角，x 向右、y 向下。

## A　带中央支撑的桥架

用 FreeCAD GUI 从空白文档建一个可编辑的单实体零件。XY 居中底板长 80、宽 50、厚 10，底面中心为原点。两端方柱中心 X=±30、Y=0，X 向宽 10、Y 向宽 20，从 Z=10 升到 30。桥板长 80、宽 20，在 XY 居中，底面 Z=30，厚 6。在 XY 平面原点画 Ø12 圆，用 Pad 的 Up to face 终止于桥板下表面，使中央柱端面跟随桥底。

交 bridge.FCStd 和真实 GUI 轨迹。每步保留实际动作及发生前图，N 步有 N+1 张主图。建模记录在保存前结束。模型保存另留凭据。提交说明给出检查结果、重试与已知问题。允许自行选择 GUI 画法，使用 GUI 控件或画布操作；模型应由本轮 GUI 输入生成。

## B　五孔圆盘的操作区域框

读取 B/actions.json 和对应的 frames。为每次 click、right_click 或 double_click 在真实动作前图画一个 click 框；普通 drag 在同一张图分别画 start、end 框。键盘、文本输入与滚轮免框。框到具体控件、列表项或几何目标，覆盖实际落点，尽量排除相邻无关目标；失败尝试也按实际落点。允许符合目标边界的不同框法。

交 boxes.json，顶层为数组。每项形如 `{"step":1,"role":"click","x":100,"y":200,"w":20,"h":16}`，四个数字为原图像素坐标及宽高，此例仅说明格式。

## C　底板与双柱的布尔融合

读取 C/actions.json 和对应的 frames。这是一段底板与两根圆柱进行布尔融合的真实操作。给全部 90 步填中文意图。描述上一步所处阶段、这一步需要做什么、动作前图看得到什么、应该执行什么操作。首步直接写目标、观察及动作。区分输入与输入并回车、显示与选中、意图与软件的实际响应。

交 intents.json，顶层为数组，每项仅含整数 step 和中文 human_intent。按真实动作写，包括错误和恢复。若画面无法确定某项信息，具体说明可见范围。
