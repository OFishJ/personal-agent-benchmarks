# 工装验收与复用评分 · v1.0

两轮分别验收同一份任务书。每轮先封存提交物或其哈希清单并停表，再重开考生交付的 STEP 和图纸。工程能力、过程分和复用结论分别报告。L5 / D4 是题目要求达到的等级。

## 分数如何给

| 维度 | 满分 | 判卷依据 |
| --- | ---: | --- |
| 建立操作能力 | 20 | 稳定使用初始远端桌面约 5 分。自主找到能批量完成实际工作并读回结果的操作方式约 10 分。形成可靠的执行与结果往返约 15 分。能重复用于后续操作并从失败中恢复可给 20 分。等效方法按实际能力给分。 |
| 取得可信几何 | 20 | 记录能读到的模型与状态 5 分，核实单位和装配坐标 5 分，获取工装实际依赖的接口几何 5 分，在目标 CAD 或交付实体上独立回读 5 分。普通文件复制成功只能证明传输能力。 |
| 验证和修正 | 15 | 用事实区分障碍 5 分，主动以代表性小样或等效低成本证据验证关键假设 5 分，发现不符后及时换法、或已有充分证据再投入完整设计 5 分。记下提示发生时点和考生此前已做到哪一步。 |
| 工程成果 | 25 | 按下表逐项给分。首轮和次轮各给一个工程分，配对总分取两轮较低值。只完成首轮时报告首轮成绩及未完成项。 |
| 同类任务复用 | 20 | 裁判能在第二轮追溯到实际沿用的工具或流程 5 分；能说明针对新接口做了哪些必要适配 5 分；两轮工程均通过且实际提速，再按节省的建设、适配和总用时给 0–10 分。满分要求第二轮以明显更低成本完成。 |

前三项按同一考生两轮中独立证明的最高能力各计一次。只有逐次看图、手工测量且未在新件上证明节省时，可以保留已取得的工程分，复用结论写“未证明”。API、脚本、工作位置本身均无固定分值。无第二轮交付时复用计 0 分，首轮工程分仍保留。

## 七项工程复核

每项证据应注明模型状态、部件、视图或测量位置、单位及结果，并可追溯到交付文件。部分可核实按已完成工作给分。以下七项均达到要求，才把该轮记为工程通过并用于同质量提速比较。

| 计时工具中的字段 | 分值 | 判卷人独立检查什么 |
| --- | ---: | --- |
| mechanical_assembly | 4 | 在 173 实体来件上按交付坐标安装夹具，核对定位面、接触与干涉、工具入口和反力路径。反驱时输出端能动，换向时用于锁止的零件能装入。 |
| powered_assembly | 4 | 换用 199 实体完整件。核对板、连接器、热垫、后盖可复装，接线可达，在带电状态下夹具仍按设计承载。 |
| startup | 4 | 按实际作用线重算 5 N·m 所需力和有效力臂，核对 ±100 N 量程、示值误差、去皮和运动起始判据；检查限流及 1 秒持续上限。 |
| backdrive | 3 | 核对相线开路、无输入锁止、双向缓慢加载及重复起动的判据。检验员应能分开记录两个方向的结果。 |
| backlash | 5 | 从实际测点位置重算 0.05° 的信号量。核对仪表分辨率、示值误差依据、加载方向、锁止间隙和支架变形。若利用原有传感器，查断开控制板后如何供电和读数。 |
| fabrication | 3 | 重开自制件 STEP，比对图纸中的关键基准、公差、材料和加工可行性，查有效螺纹、底部余量、夹具刚度和实际装拆顺序。 |
| operator_check | 2 | 让一位没有本项目经验的协助者按交付说明辨认状态、找到装夹和测量位置，并复述或执行切换步骤。分别记录实际看到的结果和留待实物采集的读数。 |

有两类错误容易漏掉。第一，接合面和孔圈可以全对，而转接板仍压在原法兰螺钉头上。裁判要查已装螺钉和工具空间。第二，锁住输入轴的连接件可能先消耗一段自由角。若把这段位移全算给关节，即使百分表有足够刻度，0.05° 的结论仍不成立。按考生采用的实际结构定量复核，夹持、消隙或独立补偿等方案均可得分。

## 怎样比较两次耗时

从考生取得当轮题面和访问条件起计时，提交停表。第二轮保留首轮工具、配置、笔记及会话。两轮记录同一考生、工位、CAD 版本、权限和资源预算。给出每轮总时间、一次性建设、按件适配、工程设计和等待时间，另记本人登录、普通协助、技术提示和环境变化。报告第二轮总历时除以首轮总历时，也对照剔除等待后的投入。只有两轮同等质量、节省可归因于实际沿用的工作，才认定同档复用。当前版本未标定固定倍数。

[计时工具](p5_trial.py)仅需 Python 3 标准库。在独立裁判目录运行。下例按实际事件逐条记录。提交清单由裁判封存，工程复核 JSON 以表中七个字段作键，每项含布尔值 `passed` 和非空证据说明 `evidence`。

```sh
python p5_trial.py session.db run1 first start --value setup --note "agent-A/station-A"
python p5_trial.py session.db run1 first phase --value design
python p5_trial.py session.db run1 first note --value help --note "现场完成登录"
python p5_trial.py session.db run1 first submit --evidence first-files.json
python p5_trial.py session.db run1 first review --evidence first-review.json
python p5_trial.py session.db run1 repeat start --value adapt --note "agent-A/station-A"
python p5_trial.py session.db run1 repeat submit --evidence repeat-files.json
python p5_trial.py session.db run1 repeat review --evidence repeat-review.json
python p5_trial.py session.db run1 pair report
```

用 `phase` 在 setup、adapt、design、wait 之间切换。技术提示以 `note --value hint` 另记。工具汇总原始耗时和两轮工程结果；分项能力分和提速归因由裁判根据材料填写。结论适用于该工位与这对同系列接口。
