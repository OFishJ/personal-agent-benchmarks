# 单机布置与现场协助

本题可以在一台实体电脑上组织。组织者分别准备考生入口、CAD 工作站和裁判资料。仓库交付题面、教学模型与评分规则；工作站由各考场按实有环境布置。

1. 在隔离的工作站或虚拟机中配置普通工程账户和 CAD。优先使用当地有适用授权的非开源 CAD，如 CATIA，以保留发现可用接口、确认接口权限和取得精确几何的工作量。本机原有的第三方许可配置不用于正式考场。缺少合适软件时可用 FreeCAD 等开源 CAD；在成绩中标明版本、公开接口的可达性和降低的难度。
2. 给考生一个真实可用的远程入口和使用它所需的地址、账号安排、工作目录与交卷位置。入口外的连接能力按考场实际网络配置生效。完整难度要求考生运行环境不能直接读取宿主文件、教师目录、虚拟盘或管理接口。把允许考生使用的工具和会话开始前已有的能力记入工位记录。
3. 在模型及派生工作文件上启用考场实际部署的内容保护。普通账户应能在授权 CAD 中打开、使用并保存模型。组织者投放前用一份教学样件确认允许的 CAD 能读回几何、普通读取或复制遵守保护规则、自制工装有允许的交付位置。记录覆盖范围。只有口头限制、或提供了预接好的工程接口时，应标作不同的工位条件。
4. 从[首轮压缩包](models/first.zip)取出两个 STEP，通过出题侧入口放入工作站。首轮交卷后再投放[次轮压缩包](models/repeat.zip)，为第二轮准备不同工作目录，两轮文件在各自目录内同名。保留考生自己的工具和工作记录。原件可留在站内，由裁判就地验收。
5. 每轮初始只给[考生任务书](../candidate/任务书.md)、本轮工作站入口和当轮来件。两轮使用同样的预算、仪表和提示规则。考生与协助者只能接触当轮材料。公开题已见过时要记录材料暴露，使用同难度自备未见件才能声称是盲测。

**现场只设一位普通协助者。** 真人或单独的子代理均可。仅给其当前可见的设备、标签和当次指令，让其连接设备、在交付后按步骤操作、报告可见现象。子代理使用干净上下文。必须由本人完成的登录另记用时。专业诊断、软件选择、建模与解决路线均由考生掌握。协助者若需要追问，原样记录请求、观察和回复。

按[校验清单](models/manifest.json)核对下载包及解压后的文件。每包仅有 P5_Full.step 与 P5_Mechanical.step，采用毫米。裁判资料及次轮压缩包放在考生账户权限之外。
