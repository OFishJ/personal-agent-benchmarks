# 04 · 受限 CAD 工位上的舵机检测工装

一位检验员有一台桌面机械臂关节、两种装配状态和一套台架仪表。考生从远端接手，在同一基台上设计能测启动输出转矩、断电反驱起动转矩和换向间隙的工装，再处理一个此前未见的同系列型号。

| 谁来用 | 材料 |
| --- | --- |
| 考生 | [三项检测工装任务书](candidate/任务书.md)。模型由组织者分轮放进工作站。 |
| 组织者 | [单机布置与现场协助](examiner/布置.md)、[首轮模型包](examiner/models/first.zip)、[次轮模型包](examiner/models/repeat.zip)、[文件校验清单](examiner/models/manifest.json) |
| 判卷人 | [分项评分、工程复核与复用计时](examiner/判卷.md) |

完整关节有 199 个实体。断电来件拆去后盖、后舱控制板和随板器件，剩下 173 个实体，前端编码器和轴系支承仍在。两项断电测试都要在这个状态下读数。带电启动则要把板、连接器、热垫和后盖装回去。工装必须给复装留出空间，同时让检验员知道测到的位移有多少可能来自工装自身。

## 设计评级 L5 / D4

第 03 题从零设计关节，本题接手已有设备。第 03 题对传动本体的设计要求更深。本题新增了从受限入口建立工作方法，以及在陌生型号上以同等交付质量显著提速两项必做工作。**L5** 取决于第二轮能否沿用第一轮的成果。**D4** 取决于工装和测量链本身的难度。即使给出工作路线，考生仍要把关节真正的换向间隙与锁止、连接和量具支承引入的位移区分开，并说明怎样分辨 0.05°。

下表估算每个模块对整题的贡献。0 表示题面没有单列要求，1–2 表示单步或成熟做法的组合，3 表示需要处理联动条件，4 表示有较强的工程权衡，5 表示该项是决定成败的主要难点。两题使用相同模块、相同权重。合计用于比较这两题的覆盖范围与工作负担，L 和 D 仍按[题库尺度](../../RATINGS.md)分别定级。

| 必做模块 | 03 关节设计 | 04 工装 | 评分理由 |
| --- | ---: | ---: | --- |
| 接手工位、建立稳定操作 | 0 | 3 | 第 04 题要从有限入口工作，现场协助者只能按指令连接和验收。 |
| 取得可用几何并核实 | 2 | 5 | 自己创建的模型可以直接查询。接手的工位则要证明取得的尺寸、姿态和接口足够支持设计。 |
| 传动本体或工装机械设计 | 5 | 4 | 从零设计行星级、电机支承比设计夹具更难。工装仍须给出完整的加载与反力路径。 |
| 载荷、工况和测量 | 5 | 5 | 一题做转矩、强度与刚度校核，另一题要让三种测试的力与微小位移各有可复核的物理含义。 |
| 装配、拆检与状态切换 | 5 | 4 | 第 03 题须证明整机可装入。第 04 题须让两种来件共用基台，并保留复装和工具空间。 |
| 独立验收与交接 | 4 | 4 | 两题都要重开实体和复核关键量。第 04 题还要使普通检验员能照说明辨认状态、完成操作。 |
| 换一个型号后复用 | 0 | 5 | 第 04 题再次验收完整交付，并观察工具、人工协助和耗时怎样变化。 |
| **模块合计** | **21 / 35** | **30 / 35** | **等权设计粗估，尚无这两题的可比考生耗时或通过率。** |

公开版提供两个型号、每个型号两份 STEP 和判卷工具。电机定转子使用本题自建的两个环形占位实体，厂家电机 CAD 留在本地。工装使用的壳体、轴系、法兰、后舱和编码器接口沿用出题模型。该版本评数字装配与测试方案，实物的转矩和回差由实际台架采集。
