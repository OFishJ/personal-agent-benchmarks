# 03 · 紧凑同轴行星舵机关节

为桌面机械臂从零设计一款 Ø80 × 62 mm 以内的同轴行星关节。考生要选定电机和轴承，建出独立的定子、转子、减速器、法兰、壳体和电控组件，给出材料，验证工况和装配顺序。交付的数字样机还要能供另一位工程师设计转矩和换向间隙测试工装。

**设计评级 L3 / D4。** L3 体现在考生要自行找出容易装不进、转不动或拆后测不了的位置，并用独立观测复验。D4 体现在同一段轴向空间同时约束齿宽、支承跨距、电机及输出法兰布置，方案还须满足启动、连续运行段和外载下的定量门槛。

首轮盲判中，GPT-6.1-Sol 用 14 分 49 秒判对了八份基于同一母型的匿名提交。两份合格件均获接受，六份故障件的退回原因均与封存答案相符。设计方为 GPT-6.2-Astra，双方均使用 xhigh。这个结果覆盖本组同族变体，对独立来源结构的判卷能力仍待实测。
