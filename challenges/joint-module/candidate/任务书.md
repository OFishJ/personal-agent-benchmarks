# 设计一个可拆检的紧凑同轴行星舵机关节

为桌面机械臂从零设计一款舵机关节。下游工程师将利用你交付的实体总成设计启动输出转矩、断电反驱起动转矩和换向间隙测试工装。需要能生产试制、可靠装入和拆检的数字样机，能查清每个接口接到哪里。

## 工况与边界

| 项目 | 设计输入 |
|---|---|
| 传动与空间 | 电机和输出同轴，采用行星减速器。完整件须落在 Ø80 × 62 mm 的圆柱包络内。含连接器本体、螺钉头、定位止口和机内线束。中心通孔自选。STEP 的 Z 轴与关节轴一致，轴心在 X=Y=0。 |
| 工作循环 | 环境 25 °C。每 30 s 周期先提供 5 N·m 准静态启动转矩，最多 1 s；再以至少 12.5 r/min 输出至少 2 N·m、持续 6 s；余下时间卸载断流。 |
| 外载 | 在输出安装面以外 25 mm 处同时施加任意方向横载 100 N 和输出端峰值扭矩。 |
| 定量限值 | 法兰面相对轴承支点的最大横移 ≤0.10 mm。输出轴屈服、关键传动件强度的设计筛选系数均 ≥2。输入锁止时输出几何空回上界 ≤1.2°。 |

## 按开发阶段留出可检查的成果

1. **布置评审。** 先给出真实电机和轴承的候选尺寸、径向与轴向空间分配及关键轴线剖面，再展开详细模型。交代怎样利用电机中心、绕组端部和壳体环带，以及选定方案的代价。
2. **详细设计。** 定子与转子必须是两个可独立选择的实体，保留真实气隙、定位、固定与传扭界面。优先采用厂家 CAD；无可用模型时按有出处的机械图复刻并标注简化。建出太阳轮、行星轮、销、行星架、内齿圈、止转结构、各轴系支承和限位。各功能轴承明确型号、数量、尺寸、安装方向与载荷依据。交付件应能通过实体核对啮合与分载布局。
3. **机电集成。** 建出承力壳体、输出法兰、机座安装面、传感器靶件与读头、控制板、功率器件、主要连接器及线束空间。说明气隙、出线、散热、电源和控制接口。给每件实际材料或外购件的材料组成。
4. **试制装配。** 写清子装配、装入方向、基准、压装受力圈、紧固工具入口和拆检顺序。选择最易卡住的装入路径做几何检查，并演示至少一个错误顺序为何不可行，或证明两种顺序都可行。保留人员能读懂的过程图。
5. **设计验证。** 用可复算模型核对运行点和启动点、传动比、受力变形、关键传动件和空回。在多个位姿检查实际传动几何。解释模型覆盖的范围、主要假设、如何测量，以及样机阶段仍须验证的项目。

## 交付

原生可编辑设计及必要外部引用，具名精确实体的完整、拆检 STEP，总布置、剖视和装配顺序图，BOM、计算源和结果、给下游的接口及三项试验交接单。两份 STEP 共用坐标系；拆检状态应保留需要运行的轴承、限位和传动链。前期布局、发现的问题、工程更改和复验写入简短阶段记录。工装由下一道题设计。

BOM 用 UTF-8 制表符文本，至少提供 ID、Material 两列，并以 ID 对应 STEP 具名实例。填写 facts.json 作为复核索引。材料数据、齿数、尺寸、气隙工作区间和载荷数字都应可追溯至原始图纸、CAD 或计算输入。

| 字段 | 内容 |
|---|---|
| roles | 键 motor、stator、rotor、input、transmission、output、supports、housing、controller、target、reader，各映射为非空的 STEP 实例名数组。supports、housing 指测试所需的支承与承力壳体。target 与 reader 的首件是实际测隙对象。 |
| removed，sensor_gap_range_mm | 移除件列表；所选感测原理允许的最小与最大工作间隙，单位 mm。 |
| planetary_stages，ratio | 每级给 sun、planet、ring 齿数，planet_count，及 fixed、input、output 三个构件名；给出总减速比绝对值。复合、非等分或变位方案另附运动方程与实际装配条件。 |
| curve_motor_rpm，running_curve_Nm，running_derating | 同一速度下可用输入转矩与折减。允许有电压、电流和 Kt 依据的低速模型。 |
| starting_input_Nm，starting_derating，total_efficiency | 短时启动可用输入、折减以及总传动效率。 |
| shaft_allowable_MPa，shaft_peak_MPa，transmission_allowable_MPa，transmission_peak_MPa | 轴和关键传动件在各自失效模式下的强度基准及设计应力。 |
| face_deflection_mm，lost_motion_deg | 上述法兰面最大横移及输出空回。 |
