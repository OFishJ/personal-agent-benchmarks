# 工位使用说明

`usb/` 是随设备交来的只读介质。`work/` 是本轮工作区，含起始组态和文本 ST。可以写入其他文本文件保存自己的笔记。工位按此轮独立的虚拟时间运行。

工具可列文件、分页读取文本或二进制、查找文字、写工作副本、操作设备和提交。读文本时 offset 按字符计，读 base64 时按原始字节计。文件名区分大小写，目录分隔符为正斜线。

设备工具提供枚举设备、编译、下发、操作员输入、推进扫描、读面板和独立轴端、恢复开工状态的动作。编译读取 `work/station.json` 和 `work/main.st`。下发载入上一次成功编译的副本并返回本次程序标记。复位保留已编辑的文件。提交后本轮封卷。

配置包含设备标识、按别名或环位置寻址、接收和发送 PDO、轴反馈对象、每转计数与工程单位。反馈对象写作“索引:子索引”。设备描述见 `usb/drive.xml`，组态参数在当前工作副本中编辑。

| ST 元件 | 含义 |
|---|---|
| D0、D1 | 操作员有符号转速请求（0.01 rpm）和停止请求 |
| D2、D3 | 总线 AL 状态和轴报警，65535 表示轴诊断暂不可用 |
| D4、D5 | 轴位置，按高低字组合的有符号 32 位值，单位为千分之一工程单位 |
| D6、D7 | 当前使能及心跳超时 |
| D8、D9、D10、D11 | 生效组态版本、扫描计数低字、已回显的程序标记和本次待回显标记 |
| D12、D13、D14 | 操作员选择的模式（0 点动、1 位置、2 速度、3 转矩）、有符号相对角度（0.001°）、有符号转矩（0.1% 额定转矩） |
| D15、D16 | 本次定时时长（4 ms 扫描数）、启动请求编号。每次按下启动生成新编号，松开或停止保持编号 |
| D17、D18、D19 | 驱动器转矩反馈（0.1% 额定转矩）、当前生效模式（失能为 -1）、启动按钮按下为 1 |
| M100、D101、D102、D103 | 程序输出的使能、转速（0.01 rpm）、心跳、程序标记 |
| D104、D105、D106 | 程序选择的驱动模式（与 D12 同编码）、相对位置指令（0.001°）、转矩指令（0.1% 额定转矩） |

轻量 ST 支持整型和布尔赋值、加减、比较、AND / OR / NOT、IF / ELSIF / ELSE / END_IF 及注释。元件在扫描间保持。单轴范围为正负 10 rpm，每个设备步长 4 ms，心跳 1 秒未改变会撤销使能。此工位提供行为模型的操作接口。

## 操作员怎样给定

`station` 的 `input` 动作接收以下字段。一次输入持续到下一次输入，虚拟时间只随 `advance` 推进。下发后先推进扫描，让程序有机会响应。

| mode | 给定及范围 | 轴接口 |
|---|---|---|
| `jog` | `rpm100`，−1000 至 1000 | 按住时给出有符号转速，松开点动后 D0 归零 |
| `position` | `position_mdeg`，−10000 至 10000 | 进入已使能的位置模式时，驱动从当时的轴位置锁存一次相对位移并闭环定位；下一段微调先停稳失能再启动 |
| `speed` | `rpm100`，−1000 至 1000 | 正值正转，负值反转；启动按钮松开时仍保留转速设定 |
| `torque` | `torque_permille`，−50 至 50；`duration_ms`，500 至 6000 | 10 表示额定转矩的 1%。驱动施加指令并回报转矩，程序管理运行时长。小转矩可以产生反馈而未克服静摩擦 |

每次 `input` 都带上所选模式的给定和布尔 `stop`。预设或松开启动按钮用 `start=false, stop=false`，按启动用 `start=true, stop=false`。按停止用 `stop=true`，此时停止优先。省略 `mode` 默认点动，省略 `start` 默认在未按停时按下启动按钮。时长向上取整到一个扫描。

用 `advance` 每次推进 1 至 250 次扫描，可多次调用。`observe` 返回面板与独立轴端的读数，包括角度、编码器计数、转速及实际施加的转矩。用 `checkpoint` 可在独立工位复测当前工作副本的双向点动，获得阶段回执后继续作答，当前轴位置和程序状态保留。`submit` 封存整份作品。
