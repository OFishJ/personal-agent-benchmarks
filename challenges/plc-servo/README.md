# 01 · 单轴伺服调试

你接手一台空载伺服工位。初始组态能够编译，轴却还没有经过点动确认。请从材料开始，用轻量 Structured Text（ST）写出一份程序，驱动同一根虚拟轴完成低速调试。[考生任务书](candidate/任务.md) · [工位接口与寄存器表](candidate/盲测工位.md)

| 阶段 | 验收动作 |
| --- | --- |
| 中验 · 双向点动 | 两个方向都能按住运行，松手和按停均能停稳。可随时调用 `station` 的 `checkpoint` 在另一台临时工位复验，之后继续作答。 |
| 终验 · 位置 | 从当前位置做正、反相对微调，编码器位移符合给定，到位后保持。 |
| 终验 · 速度 | 预设时轴静止，按下再松开启动仍持续运行；用一段时间内的轴端位移核对转速，再按停。 |
| 终验 · 转矩 | 小给定建立转矩反馈，高一些的正、负给定带动轴端；定时结束能停稳，也能提前按停。 |

考官在干净工位只下发一次提交，分别记录四项结果。四项均通过才算完成。扫描步长为 4 ms，每次实验由调用者推进虚拟时间。

## 怎样开考

下列命令均在本题目录运行。使用 Python 3.10+，无需安装依赖。

```sh
python -I -B -X utf8 examiner/blind_exam.py --show
python -I -B -X utf8 examiner/selftest.py
python -I -B -X utf8 examiner/blind_exam.py
```

第三条命令运行 JSON Lines 考场。第一行输出两条开场消息与六个函数定义。前端逐行发送工具调用，再把结果返回给考生。例如：

```json
{"tool":"list_files","arguments":{}}
{"tool":"station","arguments":{"action":"discover"}}
{"tool":"station","arguments":{"action":"observe"}}
```

每次开考都应新建模型上下文，只注册考场给出的六个工具。考生工作区在内存中，只能读取材料清单和自己的文件。源码和参考程序公开，持有仓库文件、终端、互联网或先前聊天的考生能够接触参考解。盲测时由考官持有仓库，并记下模型是否可能见过公开题。

也可以连接支持函数调用的本机 Chat Completions 兼容端点。把下面的模型名和端口换成服务中的值：

```sh
python -I -B -X utf8 examiner/blind_exam.py --local-model MODEL_NAME --port 1234
```

`submit` 冻结作品，返回交卷编号和 SHA-256。提交落在本题 `work/blind-submissions.sqlite3`，最多保留 32 份、总载荷上限 16 MiB。考官用编号判卷。报告含给定、实测结果和随机种子；传入同一种子可复跑相同给定：

```sh
python -I -B -X utf8 examiner/blind_grade.py RECEIPT_ID
python -I -B -X utf8 examiner/blind_grade.py RECEIPT_ID --seed 31415
```

## 实验边界

工位计算独立于考生程序的轴端运动和编码器计数。模型支持相对定位、速度斜坡、转矩逐步建立和简化的起动摩擦。设备描述是专为题库编写的 XML 子集。工位通过本地工具模拟编译、下发和观测，不与真实工业网络通信。

原型曾等权选取 20 个低速故障场景，其中 12 个能观察到症状并在修正后验证恢复，现有判卷在固定种子下识别了其中的 10 个。小角度微调被吞和位置运动早期忽略按停曾经漏判。公开版替换了输入材料；这组数字仅描述原型抽查。现场未知故障覆盖率、真实负载回差和高速响应仍缺乏验证。发布自检的成绩属于参考程序，本仓库没有公布真实 AI 考生的成绩。
