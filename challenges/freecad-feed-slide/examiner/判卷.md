总分 100。记录六项实得分及阻止整机放行的问题。建议首版整题通过线 80 分，并同时满足以下交付条件：指定 GUI 和 API 路线各有可核验交付，来料两类缺陷均被识别并正确处置，两个规定图样均可读，总装能从零位驱动、停在中间、反转及走完全程。该通过线是出题设计值，正式作答时间与模型通过率尚待盲测。

### 来料答案和正反对照

| 件号 | 原始文件实测与结论 | 在装配中的后果 |
| --- | --- | --- |
| P01 | 合格。160×88×8；4 个 Ø5 简化连接孔在 X=16/144、Y=±33；4 个 Ø6.6 外装孔在 X=36/124、Y=±36 | 孔距、板厚及两支座基准吻合。正确放行 |
| P05 | 合格。总长 162，Ø16 段从 u=34 到 150。两端 Ø12，手轮端 u=0…16 有距轴 5 的平面 | 双轴肩定位正确，D 面能传递转矩。简化圆柱螺纹符合题设 |
| P07 | 不合格。长 140 正确，直径实测 8.6，图纸 8。两件均须换成 Ø8 | 每根杆与每只支座孔有 0.30 径向重叠、与滑鞍孔有 0.10 径向重叠。按零位试装，单个杆/支座的公共体积约 93.87 mm³，单个杆/滑鞍约 106.81 mm³ |
| P08 | 不合格。总长 6、外圆 18、内孔 12.2、槽底 16 正确。槽宽实测 1，图纸 2。中心仍距端面 3。替换两件 | 外形和安装包络允许装配，但环槽的加工宽度错误。单独保留此错件，在 41 个行程位置均无正体积干涉。可以说明其影响配油几何，本题没有流量试验 |

稳定的区分方法是测 P08 槽底圆柱面两个轴向边界，再检查安装和全行程。只做碰撞扫描会漏报；把中性模型的简化螺纹或正确尺寸报错则计误报。原始输入和最终件应单独核对。对补件不以文件名称判断。

### 模型与传动复核

1. 重开提交，按实际映射驱动。FreeCAD 自带并能导入 Part 的 Python 可运行 `python check_assembly.py assembly.FCStd assembly-map.json --out measurements.json`。考官应使用考生文件。校准时换成 [参考装配](reference/assembly.FCStd) 和 [参考映射](reference/assembly-map.json)。参考装配属性 Drive.Turns 可直接改为任一行程内转数。独立 STEP 或其他工位交件在同一坐标系手工量测。
2. 零位、1.25、5、4.5、7.375、10 圈及回零，滑鞍左端 X 依次为 36、41、56、54、65.5、76、36。正转 1/4 圈时摇柄从 +Y 摆向 +Z。丝杠两肩 X=22 和 138；摇柄和 D 面应共转。沿行程选择考生未知的另一非整数圈数，必要时步进复查。检查中间传动、反转回差、横向窜动和返回零位。手轮轴线及原点由题面固定。
3. 脚本比较名义实体与实际实体的双向体积差，枚举映射中所有零件对。返回 non_nominal 时，回读具体尺寸并辨别拓扑、建模表示及容差。体积差大于 0.02 mm³ 用于提示复看；正体积干涉超过 0.05 mm³ 时定位到对应零件对，判是否真实穿透。名义尺寸按题面、运动位移 ±0.05 mm、必要方向角 ±0.2°。模型中另有实体、提交件引用或变化是否由上游零件传播，考官也需核实。单次静态摆位只能得对应局部分。
4. API 在干净 FreeCAD 文档或临时空目录执行原始脚本一次，再改顶面孔群距复做。只改这一项时，中心距 24→20，两列 X=8/32→10/30，Y=±24 不变；截面、端面孔与中央座孔不变。GUI 轨迹全查 N+1、时间顺序与保存，抽读起始空文档、输入尺寸、P02 油口/阶梯孔、P04 D 形贯通、P09 轴肩和末帧。在打开考生自检前记录证据步号。
