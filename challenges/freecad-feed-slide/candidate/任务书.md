# FS40 双导杆手动丝杠滑台

根据所附装配示意、零件图、中文规格和七份 STEP 文件，完成一台能由手轮驱动的滑台。交付可编辑零件和总装、来料检验报告、一张螺母零件工程图和一张总装工程图。图册中的数字为名义尺寸，单位 mm。[打开七页图册](FS40-装配示意与零件图.pdf)

### 一、制作四种零件

| 件号 | 给定材料 | 指定制作方式与交付 |
| --- | --- | --- |
| P02 端支座 | 图册 P02 页 | 从空白 FreeCAD 文档通过 GUI 画一个可编辑零件，在总装中使用两次。保留真实操作轨迹、动作前图和保存凭据 |
| P03 滑鞍 | 图册 P03 页 | 编写 FreeCAD Python API 脚本，从空文档生成零件。交可运行源文件、运行说明、生成的 FCStd。把顶面四孔沿 X 的中心距做成可调参数，孔群中心保持 X=20。默认中心距 24，改为 20 时应得到 X=10 和 30 两列，其余接口尺寸维持图纸值 |
| P04 手轮 | 下列中文规格 | 从空白文档用 FreeCAD GUI 建模，交可编辑 FCStd 和真实 GUI 记录 |
| P09 摇柄销 | 下列中文规格 | 从空白文档用 FreeCAD GUI 建模，交可编辑 FCStd 和真实 GUI 记录 |

**P04 手轮。** 取手轮外端面为局部 X=0，朝向端支座为 +X。做一个 Ø44、厚 8 的圆盘，在内侧接长 Ø20、长 8 的同轴轮毂，总长 16。中心开贯通 D 形孔，名义外圆 Ø12，圆心在轴线上；孔截面保留圆内 Y≤+5 的部分，平面到轴线距离为 5，方向与丝杠端部相合。在圆盘上再开一个 Ø5 轴向通孔，中心 (Y,Z)=(+14,0)，供摇柄销安装。

**P09 摇柄销。** 做一根同轴两段圆柱。从外端面起，先做 Ø8、长 16 的握持段，随后是 Ø5、长 8 的安装段，总长 24。两端平齐，安装段由轮外侧压入 P04 偏心孔，轴肩贴轮面。

GUI 作业可以使用访问界面控件和画布的自动化工具。所交模型应由这次界面输入生成。每段记录含 N 次实际动作、N 张动作前图和 1 张结束图；保存可共用独立记录。P03 及总装可以使用 API。保留 GUI 重试和修正，注明分别对应哪个零件。组织者可提供与题库 FreeCAD 绘图题相同的 Windows 后台工位。

### 二、检验和处理来料

从 `incoming/` 读取 P01、P05、P07 和 P08，分别与同号图纸核对。每种各交一行结论。报告中给出图纸值、来料实测值、测量位置或截面、合格与否、装配或其他功能影响及处置。对判为合格的件也列出足以支持放行的关键读数。原始来料留存，需返修或重制的件另存；总装引用你最终放行的版本。相同件号重复使用时按图册数量装入。

`supplied/` 内 P06 法兰螺母是测绘原件。P10、P11 是已简化的紧固件，可以直接使用。P01 至 P11 的数量以 S-00 明细为准。紧固件头部按包络建模。M3/M5 内外螺纹在本卷按公称直径光孔或圆柱表示，传动副按 Tr16×4 LH 单线左旋表示，丝杠和螺母的几何包络按图和给件。

### 三、装配并演示传动

固定底座。取底座左端面 X=0、纵向中面 Y=0、底面 Z=0。以手轮位于左端为零件方向基准。两端支座相对布置，衬套由两外侧装入，油孔方向按 S-01。摇柄销、手轮和丝杠同步转动；螺母、滑鞍和法兰螺钉一起沿 X 移动。连接两端支座的导杆轴线平行于丝杠。装配应保留每个安装实例，使考官可以单独选择、测量和驱动。

手轮与 D 形轴段、摇柄销与轮孔、导杆与端支座按压装连接处理，模型使用名义接触尺寸。衬套沿支座孔定位，支座顶面的油口须和衬套环槽对应。

交一份可重复驱动的原生 FreeCAD 装配。允许装配工作台、表达式或脚本驱动。用同一输入累计手轮转数或角度；正转由手轮端向 +X 看为顺时针。零位滑鞍左端 X=36，正转 10 圈后 X=76。报告从零位到 1.25 圈、5 圈，接着反转半圈，再到行程终点的实测位置。检查滑鞍横移和随转、丝杠轴向窜动及零件干涉。理想连接允许接触或间隙；装配几何重合造成的正体积穿透须说明。验收读数容差为位移 ±0.05 mm、必要方向角 ±0.2°。

附驱动说明和实例对照。判卷程序支持数值属性以及 `turns`、`deg` 两种单位，可按 [映射样例](assembly-map.example.json) 填实际对象名。其他可驱动实现说明打开文件、施加同一输入和读数的方法。如需外部零件或本地驱动，一并提交，验证复制到新目录后仍可重开。

### 四、出两张工程图

1. **P06 法兰螺母零件图。** 测量给定 3D 模型，选择投影和剖视，使另一人可以重建它。标清法兰轮廓、厚度、筒身外径与长度、内孔、两只安装孔的直径及带方向的孔位。注明模型内孔采用的实测简化直径，以及名义传动螺纹 Tr16×4 LH。投影应能分清孔组左右手性。
2. **FS40 总装工程图。** 从最终装配出图，零位绘制。给出主视或纵剖、第二投影视图、必要的局部表达、件号及完整明细。清楚表示衬套和轴肩的轴向定位、螺母法兰的安装关系、导杆位置、安装孔距、总体外形、轴高及工作行程。总装示意图是开工材料，可自行选择更有表达力的视图。两张各交可编辑工程图源文件及 PDF，写明单位、比例、投影法、图名和图号。

### 五、提交

把原生模型、生成脚本与复现说明、GUI 证据、来料检验及修正件、装配驱动与测量报告、两张工程图放入同一提交目录，并附入口说明。外购简化件与本轮自制件在明细中分别注明。若某一环节有未完成项，列出该项和已完成工件，其他部分仍可独立得分。
